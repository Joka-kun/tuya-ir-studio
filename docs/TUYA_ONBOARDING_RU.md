# Подключение совместимого ИК-шлюза Tuya

Эта инструкция относится **к подключению физического шлюза**, а не к импорту кнопок из облака.

## Что понадобится

Совместимый ИК-шлюз Tuya, Home Assistant с правами администратора и оригинальный физический ИК-пульт для обучения. Для QR-входа нужен доступ к Smart Life/Tuya. При ручном подключении — Device ID, Local Key и локальный IP или имя хоста шлюза.

## Пошагово

1. Установи Tuya IR Studio через HACS, перезапусти Home Assistant и открой **Настройки → Устройства и службы → Добавить интеграцию**.
2. Выбери **Tuya IR Studio** и способ настройки: **Smart Life/Tuya по QR**, **действующая сессия Tuya** или **вручную по локальным данным**.
3. Для QR найди User Code в Smart Life/Tuya, отсканируй QR-код телефоном, выбери физическое ИК-устройство и нужный родительский шлюз. Для дочернего устройства может потребоваться `node_id` или `uuid`; это не то же самое, что Device ID шлюза.
4. Дождись поиска шлюза в LAN либо введи его IP/имя вручную. Проверь версию протокола и Local Key. Уже подключённый шлюз повторно добавлять не нужно.
5. Открой панель **Tuya IR Studio** в боковом меню, создай пульт, добавь нужные кнопки и нажми **«Обучить по порядку»**. Используй оригинальный ИК-пульт и проверь реакцию устройства.
6. Перезапусти Home Assistant и повтори проверку отправки. Для проверки автономности отключи **только Интернет**, сохранив локальную сеть.

## Принципиальные ограничения

- QR **не импортирует** кнопки, профили пультов Smart Life или готовые ИК-коды из облака.
- Выбор типа устройства изменяет только иконку, а не наполняет пульт несуществующими кнопками.
- Успешный вызов HA не гарантирует, что устройство физически отреагировало.
- Кондиционеры и некоторые прошивки используют особые пакеты команд.
- Никому не отправляй Local Key, QR-токены или полное содержимое `.storage`.
